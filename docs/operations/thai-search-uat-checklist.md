# แบบตรวจการค้นหาภาษาไทย (UAT) — สำหรับเจ้าหน้าที่

ทดสอบช่องค้นหาของเว็บไซต์ใหม่ด้วยเนื้อหาจริงที่ย้ายมาจากเว็บไซต์เดิม (#238) ผลของท่านช่วยตัดสินว่าการค้นหาแบบนี้ใช้ได้จริงหรือต้องเปลี่ยน
(ADR 0002) ผู้ดูแลระบบจะส่งลิงก์ให้ในวันทดสอบ ลิงก์ใช้ได้เฉพาะช่วงเวลาทดสอบ

## ก่อนเริ่ม

- ใช้อุปกรณ์ของท่านเองตามปกติ (มือถือ แท็บเล็ต หรือคอมพิวเตอร์) และจดว่าใช้อะไร เช่น "มือถือ Android, Chrome"
- เว็บไซต์นี้เป็นฉบับทดสอบ ใช้ได้เฉพาะการอ่านและค้นหา ไม่มีการเข้าสู่ระบบหรือแก้ไขข้อมูล
- ค้นหาจากช่องค้นหาบนหน้าแรก หรือเลือกเมนู "ค้นหา" แล้วลองเลือกกลุ่มผลการค้นหา (ทุกประเภท ข่าวสาร เอกสาร ITA ฯลฯ) ด้วย

## สิ่งที่ควรลองค้นหา

ลองค้นด้วยคำที่ท่านหรือประชาชนใช้ค้นจริง ไม่ต้องครบทุกข้อ แต่ควรลองหลายแบบ:

1. **ชื่อเรื่องที่ท่านรู้ว่ามีอยู่** ทั้งชื่อเต็มและบางส่วนของชื่อ เช่น ข่าว กิจกรรม ประกาศ หรือเอกสารที่ท่านเคยลงในเว็บไซต์เดิม
2. **คำสั้น ๆ** คำเดียว 2–3 พยางค์ ที่ใช้บ่อยในงานสาธารณสุข
3. **คำประสมหรือวลียาว** ที่ไม่มีการเว้นวรรค
4. **สองคำขึ้นไปเว้นวรรค** เช่น ชื่อโครงการกับชื่อตำบล
5. **คำย่อและคำเต็ม** ทั้งแบบมีจุดและไม่มีจุด เช่น ชื่อย่อของหน่วยงานหรือตำแหน่ง แล้วเทียบกับคำเต็ม
6. **ตัวเลข** เช่น ปีงบประมาณ ปี พ.ศ. หรือเลขที่ประกาศ ทั้งเลขไทยและเลขอารบิก
7. **ชื่อสถานที่และชื่อเฉพาะ** เช่น ชื่อตำบล หมู่บ้าน หรือโรงพยาบาลส่งเสริมสุขภาพตำบล
8. **คำที่สะกดได้หลายแบบหรือพิมพ์ผิดง่าย** เช่น คำที่มีการันต์ วรรณยุกต์ หรือสระที่มักพิมพ์สลับกัน
9. **ตัวชี้วัด ITA** ด้วยรหัสหรือชื่อของตัวชี้วัด (MOIT)
10. **คำภาษาอังกฤษ** ที่อาจอยู่ในเนื้อหา

## สิ่งที่ควรจดสำหรับแต่ละครั้งที่ค้นหา

| ข้อ | สิ่งที่จด |
| --- | --- |
| คำค้น | พิมพ์ตามที่ค้นจริง |
| กลุ่มที่เลือก | ทุกประเภท หรือกลุ่มอื่น |
| สิ่งที่คาดว่าจะพบ | ชื่อเรื่องที่ท่านต้องการหา (ถ้ามี) |
| พบหรือไม่ | พบในผลลำดับที่เท่าไร หรือไม่พบเลย |
| ผลที่ไม่เกี่ยวข้อง | มีผลที่ไม่เกี่ยวข้องอยู่ด้านบนหรือไม่ |
| ความเร็ว | เร็ว (ไม่ถึง 1 วินาที), พอใช้ (1–3 วินาที) หรือช้า (เกิน 3 วินาที) |
| อื่น ๆ | ข้อความที่อ่านไม่ออกหรือแสดงผิด รูปที่ไม่ขึ้น หรือหน้าที่เปิดไม่ได้ |

ตัวอย่างการจด:

> คำค้น: (คำที่ค้น) — กลุ่ม: ทุกประเภท — คาดว่าจะพบ: (ชื่อเรื่อง) — พบ ลำดับที่ 2 — ไม่มีผลที่ไม่เกี่ยวข้อง — เร็ว — อุปกรณ์: มือถือ iPhone, Safari

## สรุปท้ายการทดสอบ

ตอบสั้น ๆ 3 ข้อ:

1. โดยรวมท่านหาสิ่งที่ต้องการเจอหรือไม่
2. คำค้นแบบไหนที่หาไม่เจอหรือได้ผลแปลก
3. ความเร็วของการค้นหารับได้หรือไม่
